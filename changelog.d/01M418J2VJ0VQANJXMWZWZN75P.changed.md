goway run -- CMD runs a command on a host from a fresh hard-linked work directory with a warm per-repository cargo target slot (and sccache when installed), streams stdout and stderr untouched, exits with the command's code (128+N on signals, 130 on Ctrl-C, 125 for goway failures), stops the remote job when interrupted, removes the work directory unless --keep, and writes host, arch and address with --report.
