Circle roster writes (`ops.jsonl`, `heads.json`) are no longer recorded in the change log, and `goway undo` refuses to restore an older roster file (including entries from earlier versions), so undo cannot roll a roster back past anti-rollback. `goway circle sync` stores only offered ops that verify and apply, and new admit/revoke/admin ops cite only applied ops as parents, so an unverified op can no longer become a head that later ops depend on.
